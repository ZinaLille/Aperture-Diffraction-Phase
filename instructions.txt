 2. 训练（train.py）
================================================================

python train.py --data data/v2_nf1_thick --groups 1 --models physics --epochs 60 --out runs/v2_nf1_ref

# 2.6 相位反演卡住时换初始化重训
python train.py --data data/v2_nf1_thick --groups 1 --models phase --phase-init random --epochs 100 --out runs/v2_nf1_r

================================================================
 5. 常用参数
================================================================
【generate_v2.py】
  --samples 1000            光阑数
  --nf 1                    只生成指定 NF 组（可给多个）
  --grid 256 --pitch-um 10 --wavelength-nm 532
  --glass-shared            整份数据共用一块屏（主用例）
  --glass-correlation-um F  相关长度；越小越"磨砂"
  --glass-rms-rad F         相位起伏 rms（rad）
  --glass-preset NAME       weak / moderate / strong / groundglass（预设）
  --hologram-fraction F     把比例 F 的样本换成密集条纹掩模
  --hologram-mode M         binary / gray / both
  --save-clean              额外保存无屏图样
  --skip-validation         跳过数值验收（仅冒烟用）

【train.py】
  --data DIR --out DIR      输出目录必须不存在
  --groups 1                只训练指定 NF 组
  --models phase | phase_residual | physics
  --screen-mode phase | complex       复振幅屏多学一个振幅 a(x)
  --background none | map             再学一张非负背景 B(x)
  --amp-grid 16             振幅参数化粒度（0 = 全分辨率）
  --propagator asm | hybrid           屏幕必须走 ASM
  --phase-lr 0.02           屏幕参数的学习率
  --phase-init zero | random
  --epochs 60 --batch-size 16 --lambda-freq 0.02 --lr 3e-4
  --seed 42 --device auto|cpu|cuda

【design.py】
  --checkpoint PATH         必须是 phase / phase_residual 的 best_model.pt
  --char Z | --target FILE
  --modulation binary|gray|phase
  --steps 1500 --restarts 2 --lr 0.05
  --true-phase PATH         只用于验收，不参与优化
  --design-background signal|total    signal = 只用信号（默认，推荐）
  --out DIR

 7. 判据
================================================================
训练学对没有：selection.json 的 test.mae
    1e-5 量级  -> 抓到了
    1e-3 量级  -> 有非相位偏差，或相位反演陷局部极小
    1e-2 以上  -> 模型形式不成立，先别做设计
残差图（train_result.png 最后一列）：白 = 只是相位没抓全；有结构 = 有东西没被建模
设计可信度：comparison.png 的 ②（φ̂ 正向）；有真值相位时看 ③
